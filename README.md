# audio.lgbt для Windows

Нативный клиент audio.lgbt без WebView, браузерного процесса и локального веб-сервера. Один установщик, совместимость с браузером, сквозное шифрование аудио, видео и чата.

[Скачать установщик](https://github.com/aes-gcm/audio.lgbt-windows/releases) · [Сервер и сайт](https://github.com/aes-gcm/audio.lgbt) · [Сборка из исходников](desktop/README.md)

## Свой сервер

По умолчанию приложение подключается к `https://audio.lgbt`. Кнопка «Сервер» на стартовом экране позволяет указать другой HTTPS URL. Адрес и имя сохраняются, история комнат разделена по серверам. Если владелец сервера ограничил создание комнат аккаунтами, первый участник пустой комнаты автоматически увидит форму входа. После входа подключение продолжится само. К уже открытой комнате гости подключаются без аккаунта.

Чтобы разместить сервер, используйте [Docker-инструкцию](https://github.com/aes-gcm/audio.lgbt/blob/main/docs/SELF-HOSTING.md). Этот репозиторий скачивать на сервер не нужно.

## Возможности

- Устройства и громкость в звонке, тест вывода, громкость участника до 200%.
- Камера, экран/окно с превью, 720p–4K и 15/30/60 FPS, смена качества во время показа.
- Звук демонстрации отдельно от микрофона, полный экран и отдельная громкость просмотра.
- Настройки, приглашение и участники поверх звонка; чат сбоку.
- Автоматическое обновление при запуске с прогрессом скачивания и установки.

Официальные обновления приходят из GitHub aes-gcm/audio.lgbt-windows независимо от выбранного сервера звонков. Для независимого форка можно отключить их флагом сборки `OfficialUpdates=false`.

## Проверки

Go 1.26, .NET 10 и Visual Studio C++ Build Tools нужны только для разработки. `go test ./...` запускает проверки движка; тест двух клиентов через SFU включается переменной `AUDIO_TEST_SERVER=http://127.0.0.1:8080/` с запущенным dev-сервером. Команды Windows-проверок приведены в [desktop/README.md](desktop/README.md). Chrome interoperability: `npm ci`, `npx playwright install chrome`, затем `BASE_URL` и `NATIVE_ENGINE` для `test/e2e/native-client.cjs`.

Версии пока отмечены preview; установщик без подписи издателя. Синтетические тесты не заменяют проверку физической камеры и субъективного качества звука. ARM64 ещё требует полноценной проверки на соответствующей Windows.
